# Banking Data Engineering Platform

End-to-end banking data engineering project using MySQL, PySpark,
Kafka, Flink, dbt and Power BI.

## Domains

- Customer
- Accounts
- Transactions
- Loans
- Cards
- Payments
- Fraud
- KYC/AML
- Branches
- Digital Banking

## Architecture

MySQL OLTP → Staging → Data Lake → Data Warehouse → BI
